## 六、损失函数总览

```
┌──────────────────────────────────────────────────────────────────┐
│                        损失函数构成                               │
├─────────────────────────┬──────┬──────────────────────────────────┤
│         名称             │ 权重 │           说明                   │
├─────────────────────────┼──────┼──────────────────────────────────┤
│  loss_ce                │  1.0 │ Focal Loss (α=0.25, γ=2)        │
│  loss_bbox              │  5.0 │ L1 边界框回归                     │
│  loss_giou              │  2.0 │ GIoU Loss                       │
│  loss_ce_dn             │  1.0 │ DN 去噪分类损失                   │
│  loss_bbox_dn           │  5.0 │ DN 去噪回归损失                   │
│  loss_giou_dn           │  2.0 │ DN 去噪 GIoU 损失                │
│  loss_ce_{0..4}         │  1.0 │ 辅助解码层 0-4 (中间监督)         │
│  loss_bbox_{0..4}       │  5.0 │ 辅助解码层回归                    │
│  loss_giou_{0..4}       │  2.0 │ 辅助解码层 GIoU                  │
│  loss_ce_interm         │  1.0 │ Encoder 输出监督                  │
│  loss_bbox_interm       │  5.0 │ Encoder 输出回归                  │
│  loss_giou_interm       │  2.0 │ Encoder 输出 GIoU                │
│  ───────────────        │  ──  │ ──────────────────────────────── │
│  loss_scene_light  [新] │  0.1 │ 光照分类 CE (bright/dim/dark)     │
│  loss_scene_density[新] │  0.1 │ 密度分类 CE (sparse/medium/dense) │
│  loss_weight_entropy[新]│ 0.01 │ 模态权重熵正则 (-Σ w_i log w_i)   │
└─────────────────────────┴──────┴──────────────────────────────────┘

阶段一 (Epoch 1-5):  仅辅助损失 (loss_scene_light + loss_scene_density)
                     目的: Scene Query 先学会 "看懂场景"

阶段二 (Epoch 6-30): 检测损失 + 辅助损失 × 0.1 + 熵正则 × 0.01
                     目的: 联合学习三模态融合检测

阶段三 (Epoch 31-50):仅检测损失
                     目的: 精化收敛，提升高 IoU 定位精度
```

## 七、数据流全链路

```
  [磁盘]                              [GPU]
  ───────                              ─────

  visible/*.jpg ──→ load_rgb() ──→ visible_t [3,800,800]
  infrared/*.jpg ──→ load_rgb() ──→ infrared_t [3,800,800]
  depth/*.png ─────→ load_depth() → depth_t [1,800,800]  + depth_mask
  labels/*.txt ────→ load_label() → boxes [N,4] + labels [N]
                                          │
                                   ┌──────▼──────┐
                                   │  target dict │
                                   │  + light_label│  ← 自动生成
                                   │  + density_label│ ← 自动生成
                                   └──────┬──────┘
                                          │
                          ┌───────────────▼────────────────┐
                          │  collate_fn_multimodal()       │
                          │  samples = {rgb, ir, depth}    │
                          │  targets = [{...}, ...]        │
                          └───────────────┬────────────────┘
                                          │
                          ┌───────────────▼────────────────┐
                          │  DINO.forward(samples, targets)│
                          │                                │
                          │  ① Backbone(rgb) → features    │
                          │  ② input_proj → srcs [×4]      │
                          │  ③ ir_encoder(ir) → ir_feat    │
                          │  ④ depth_encoder(depth) → d_feat│
                          │  ⑤ scene_fusion(srcs,ir,d)     │
                          │     → fused_srcs + scene_outputs│
                          │  ⑥ transformer(fused_srcs)     │
                          │     → pred_logits, pred_boxes  │
                          │  ⑦ out['scene_outputs'] = ...  │
                          └───────────────┬────────────────┘
                                          │
                          ┌───────────────▼────────────────┐
                          │  SetCriterion.forward()        │
                          │                                │
                          │  ① Hungarian Matcher           │
                          │  ② detection losses            │
                          │  ③ scene losses (from targets  │
                          │     & scene_outputs)           │
                          │  ④ DN losses                   │
                          └───────────────┬────────────────┘
                                          │
                                   ┌──────▼──────┐
                                   │  losses.sum()│
                                   │  .backward() │
                                   │  optimizer   │
                                   │  .step()     │
                                   └──────────────┘
```
